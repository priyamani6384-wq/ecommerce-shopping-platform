## Project Overview
Build a complete e-commerce shopping platform using Django framework with MySQL database. This application will feature product catalog, shopping cart, user authentication, order processing, and payment integration.

## Features Implemented
- User Authentication: Register, Login, Logout, Profile management using Django's built-in auth
- Product Catalog: Product listing with categories, filters, search functionality
- Shopping Cart: Add/remove items, update quantities, cart total calculation
- Order Management: Checkout, order history
- Admin Panel: Django admin
- Responsive UI: Bootstrap 5

## Tech Stack
- Python 3.8+, Django 4.2
- MySQL (with SQLite fallback)
- HTML, CSS, Bootstrap 5

## Setup Instructions
1. git clone https://github.com/priyamani6384-wq/ecommerce-shopping-platform.git
2. python -m venv venv
3. pip install -r requirements.txt
4. python manage.py migrate
5. python manage.py createsuperuser
6. python manage.py runserver
